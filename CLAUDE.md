# ha-ariston-ebusd

**This repo is public.** It is the shareable part of a private setup, so nothing here may name the house it came
from: no hostnames, IP addresses, serial device paths, add-on slugs, room or person names, coordinates, keys or
passwords. Use placeholders such as `<your-ha-host>` and say in a comment what goes there.

Anything that fits only one house (an extra zone, a thermostat that needs a correction) is optional and marked as
such, so that someone else can leave it out.

The plan behind this repo, and the private material it is drawn from, are outside it: the `home-automation`
project in the owner's atlas.
